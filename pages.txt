For FROX, I'd prioritize these five pages inside the studio:
- Model Router: choose chat, coding, image, voice, SFX, or 3D based on intent.
- Verifier: check outputs and decide whether to accept, retry, or correct.
- Pipeline Editor: visualize and configure the chain between specialized models.
- Dataset Quality: detect duplicates, bad answers, missing fields, and evaluation leakage.
- Evaluation Dashboard: compare model versions before and after fine-tuning.
You don't need to expose this studio publicly. Make it a protected workspace for you and authorized collaborators.

How I'd actually organize the navigation
Don't put 200 links into the sidebar. Organize the site into a small number of clear workspaces.

Create
Chat, Image, Voice, Sound Effects, 3D, Coding




Library
History, projects, files, favorites, collections




AI Studio
Models, datasets, fine-tuning, router, verifier, evaluations




Developers
API keys, documentation, playground, usage, logs




Account
Profile, settings, security, billing, support



What to build first
Here is the order I'd recommend so you don't spend months building pages before the AI actually works through them.
Phase 1
Launch

Core platform
Homepage, login/signup, chat, image, voice, coding, 3D, history, settings, profile, basic dashboard, error pages, privacy and terms.


Phase 2
Improve

Better user experience
Search, folders, libraries, batch generation, exports, audio history, 3D viewer, usage tracking, notifications and help center.


Phase 3
AI Studio

Your model infrastructure
Model registry, datasets, training jobs, router, verifier, pipeline editor, evaluations, deployment and monitoring.


Phase 4
Expansion

Full ecosystem
Public API, developer platform, billing, teams, community, custom assistants, workflow automation and marketplace.
